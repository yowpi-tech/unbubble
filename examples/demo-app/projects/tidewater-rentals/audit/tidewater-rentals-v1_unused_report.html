6b · Variáveis de cor e fonte sem uso

Variáveis (design tokens) definidas pelo usuário que não são referenciadas por nenhum elemento nem estilo (nenhum var(--color_<id>) / var(--font_<id>)). Ids de token colidem com ids de elemento e o tema é duplicado no export, então a contagem crua do id é enganosa — por isso usamos a forma var(). Onde excluir no editor: aba Styles → seções Color variables / Font variables (o App Search Tool não indexa variáveis — procure na própria lista). Entradas “Pasted Color #<id>” são criadas automaticamente pelo Bubble quando elementos copiados de outro app são colados; ficam no fim da lista, com nomes quase iguais e muitas vezes a mesma cor.

O evento está ligado a um element_id que não existe na árvore de elementos da própria página/reusável. Duas causas: o elemento foi deletado, ou foi movido para um reusável — o “convert to reusable” do Bubble move os elementos, mas deixa para trás o workflow do container original (o elemento ganha workflows novos dentro do reusável). Nos dois casos o workflow listado nunca dispara — a coluna “Onde está o elemento” mostra a evidência. Confiança alta.

Metodologia & limites

Pages: id interno referenced by ChangePage/Link.page/MobileNavigate or anywhere in content. Reusables: definition id used as a CustomElement.custom_id. Backend: APIEvent exposed or targeted by ScheduleAPIEvent(OnList). Option sets: token option.<name>. Plugins: element/action type prefix <id>- or config keys. Styles: "style":"<id>". Data fields: field key referenced beyond its declaration (in expressions/workflows/searches) or named in a JS/HTML script; Data types: custom.<type> referenced, any field used, or exposed via exposed_api. Limits: direct-URL / email / iframe / dynamic navigation are not statically detectable (hence page confidence levels); orphan plugin names are not stored in the export; field keys shared across tables are treated conservatively (marked used if referenced on any table); Data-API-exposed fields/tables may have external consumers not visible in the export.
